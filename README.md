# Bendit TV — ทีวีจำลองจากคลัง Plex / Jellyfin / Emby (Android TV / Nvidia Shield)

แอปสร้าง "ช่องทีวี" จากหนัง/ซีรีส์ในเซิร์ฟเวอร์ของคุณ เล่นต่อเนื่องตามตารางเวลาแบบทีวีสด
(ช่อง Action / Comedy / Drama / Sci-Fi ฯลฯ และช่องตามเครือข่ายของซีรีส์) ธีมนีออนล้ำสมัย
ไอคอนช่องวาดเอง 27 แบบ

## Build เป็น APK (ทางที่แนะนำ: GitHub Actions)

1. สร้าง repo ใหม่บน GitHub (ถ้าอยากให้ Shield โหลดผ่านลิงก์สั้นๆ ให้ตั้งเป็น Public)
2. แตกไฟล์ zip นี้ แล้ว push ทั้งโฟลเดอร์ขึ้น branch `main`
   ```
   git init && git add . && git commit -m "NovaTV"
   git branch -M main
   git remote add origin https://github.com/<you>/novatv.git
   git push -u origin main
   ```
3. เปิดแท็บ **Actions** → workflow "Build APK" (ใช้เวลาราว 5–10 นาที)
4. โหลด `NovaTV.apk` จาก Artifacts ของรันนั้น (หรือจาก Releases → "latest")

ทางเลือก: เปิดโฟลเดอร์นี้ด้วย Android Studio แล้วกด Build → Build APK(s)

## ลงบน Shield

- เปิด Settings → Device Preferences → About → กด Build 7 ครั้ง → เปิด Developer options → Network debugging
- บนคอม: `adb connect <IP ของ Shield>` แล้ว `adb install NovaTV.apk`
- หรือลงแอป **Downloader** บน Shield แล้วพิมพ์ลิงก์ของ APK (ต้องอนุญาต "Install unknown apps")

## การใช้งาน

| ปุ่มรีโมต | ทำอะไร |
|---|---|
| ▲ / ▼ (หรือ CH+/CH-) | เปลี่ยนช่อง |
| OK | เปิดแถบควบคุม (Pause / Restart / Go Live / Guide / Channel Surf / Audio & Subs / Info) กด ◀ ▶ เลือกปุ่ม แล้วกด OK |
| ◀ (ตอนยังไม่มีแถบควบคุม) / Menu | เปิดผังรายการ (Guide) |
| ▶ (ตอนยังไม่มีแถบควบคุม) / ปุ่ม CC | เมนู **เสียง / ซับไตเติล** |
| Info | แสดง/ซ่อนกล่องข้อมูลรายการ (ความละเอียด, HDR, FPS, เสียง, ซับ) |
| Play/Pause, FF, RW | หยุด / เล่น, ข้าม ±30 วินาที (ตอน Direct Play) |
| Back | ปิดหน้าต่างที่เปิดอยู่ / ซ่อนแถบควบคุม |

- **Pause / Restart** → เข้าโหมด TIME-SHIFT (ดูเลื่อนเวลา) กด **Go Live** เพื่อกลับไปจุดที่ตารางกำลังฉายจริง
- **Guide**: มีเส้นประแนวตั้งทุกครึ่งชั่วโมง เส้นแดง = ตอนนี้ เส้นฟ้า = เวลาที่รายการที่เลือกอยู่จะจบ มีหน้าจอ preview สดมุมขวาบน และแผงรายละเอียด (เรื่องย่อ, เรทติ้ง, เวลาเหลือ)
- ในผังรายการ กด ▲/▼ เพื่อเปลี่ยนช่อง จะไปที่รายการที่กำลังฉายอยู่ของช่องนั้นเสมอ
- **Channel Surf**: แผงด้านขวา เลื่อนดูช่องอื่นพร้อมรายการที่ฉายอยู่ กด OK เพื่อเปลี่ยนช่อง
- **เมนูเสียง/ซับ**: โชว์ความละเอียด (4K / Full HD / HD / SD), HDR / Dolby Vision / SDR, FPS, รูปแบบเสียง (DTS-HD MA, Dolby TrueHD, DTS, Dolby Digital ...) และชนิดซับ เช่น Thai (SRT) / Thai (PGS)
- **ปรับซับ**: ในเมนูเสียง/ซับ มีแถว Subtitle position (ขึ้น/ลง) และ Subtitle delay (เร็ว/ช้า) กด ◀ ▶ ปรับ, OK = รีเซ็ต ใช้ได้กับซับแบบข้อความ (SRT/ASS/VTT) เท่านั้น ซับภาพ (PGS) และโหมด transcode ปรับไม่ได้

ในผังรายการเลื่อนด้วยปุ่มลูกศร กด OK เพื่อเข้าช่อง และปุ่ม SETTINGS มุมขวาบนเพื่อจัดการเซิร์ฟเวอร์

เริ่มครั้งแรก: เข้า Settings → Add server
- **Plex**: กด "Link with plex.tv" แล้วใส่โค้ดที่ plex.tv/link (หาเซิร์ฟเวอร์ให้อัตโนมัติ) หรือกรอก URL + token เอง
- **Jellyfin / Emby**: ใส่ URL (เช่น `http://192.168.1.10:8096`) กับชื่อผู้ใช้/รหัสผ่าน
- เพิ่มได้หลายเซิร์ฟเวอร์พร้อมกัน เรื่องซ้ำข้ามเซิร์ฟเวอร์จะถูกรวมเหลือเรื่องเดียว

## ซับไตเติล และ เสียง

- ซับที่ฝังในไฟล์ (SRT/ASS/PGS ฯลฯ) และไฟล์ซับแยกจากเซิร์ฟเวอร์ แสดงในเมนู ▶ ได้เลย
- Settings → PLAYBACK ตั้งภาษาซับ/เสียงที่ชอบ (Thai / English / Japanese / Korean / Chinese) แอปจะเลือกให้อัตโนมัติทุกรายการ
- เลือกซับจากเมนู ▶ ครั้งเดียว แอปจะจำภาษานั้นไว้ใช้กับรายการถัดไป

## Transcode ผ่านเซิร์ฟเวอร์ (Settings → PLAYBACK)

| โหมด | ทำอะไร |
|---|---|
| DIRECT PLAY (ค่าเริ่มต้น) | เล่นไฟล์ต้นฉบับตรงๆ |
| SMART | เซิร์ฟเวอร์แปลงเฉพาะส่วนที่ Shield เล่นไม่ได้ (เช่นเสียง DTS, bitrate เกินกำหนด) นอกนั้นส่งต่อเฉยๆ |
| ALWAYS TRANSCODE | แปลงเป็น H.264 / AAC ทุกครั้งตาม bitrate ที่ตั้ง (เหมาะกับเน็ตช้า/ดูนอกบ้าน) |

- ใช้ HLS ของ Jellyfin / Emby / Plex ในโหมดนี้ซับจะถูก "ฝังติดภาพ" โดยเซิร์ฟเวอร์ (รองรับซับแบบภาพ PGS ด้วย)
- ถ้าเซิร์ฟเวอร์ transcode ไม่ผ่าน แอปจะสลับเป็น Direct Play ของรายการนั้นให้อัตโนมัติ
- ต้องเปิด Hardware/Software transcoding ในเซิร์ฟเวอร์ (Plex ต้องมี Plex Pass สำหรับ HW transcoding)

## ช่อง: มี 2 แบบเท่านั้น (รวมไม่เกิน ~48 ช่อง)

1. **ช่องสตูดิโอ/เครือข่าย** (ต้องมีอย่างน้อย 4 เรื่อง) จับคู่ตามนี้:

| สตูดิโอ / network | ช่อง |
|---|---|
| Warner Bros., New Line, DC | HBO |
| Universal | NBC |
| Paramount | CBS |
| 20th Century | FOX |
| Disney, Pixar, Marvel, Lucasfilm | Disney+ |
| Columbia, Screen Gems, Sony | Sony |

   และ network ของซีรีส์ เช่น ABC, CBS, NBC, FOX, FX, HBO, Netflix, Apple TV+, Prime, AMC ฯลฯ (ดู `RealChannels.all` ใน ChannelBuilder.kt) ถ้าหนังมีหลายสตูดิโอ จะเข้าช่องของสตูดิโอที่อยู่ก่อนในรายการ
2. **ช่อง genre** (Action, Comedy, Drama, Sci-Fi ...) เติมให้ครบจำนวนช่องสูงสุด (`MAX_CHANNELS = 48`) โดยเรียงจากช่องที่มีเรื่องมากที่สุด

ช่อง "ตั้งชื่อแปลกๆ" แบบ network ทั่วไปถูกตัดออกแล้ว ข้อมูลสตูดิโอของหนังได้มาตอนซิงก์คลัง เปิดแอปครั้งแรกหลังอัปเดตให้รอซิงก์ให้เสร็จก่อน
ถ้าอยากให้รายการเริ่มตรงชั่วโมง/ครึ่งชั่วโมง ตั้ง `RealChannels.SLOT_MS = 30 * 60_000L` (ค่าเริ่มต้น 0 = เรียงต่อกัน)

## โลโก้ช่อง

แอปวาดโลโก้จริงของแบรนด์ให้ไม่ได้ (เป็นเครื่องหมายการค้า) จึงแสดง **ชื่อช่อง** ไว้ก่อน แล้วอัพโหลดโลโก้เองได้ทีหลัง:

1. Settings → **CHANNEL LOGOS** → กด **UPLOAD LOGOS FROM PHONE / PC**
2. TV จะแสดงที่อยู่ เช่น `http://192.168.1.20:8080` เปิดที่มือถือ/PC ที่ต่อ Wi-Fi เดียวกัน
3. เลือกช่อง → เลือกรูป (PNG โปร่งใสสวยที่สุด, JPG/WebP ก็ได้) → Upload โลโก้ขึ้นบน TV ทันที (ปุ่ม Remove logo เพื่อกลับเป็นชื่อช่อง)
4. หน้าอัพโหลดปิดเองเมื่อออกจาก Settings (ไม่มีรหัสผ่าน ใช้ได้เฉพาะในเครือข่ายบ้าน)

ลำดับที่แสดง: โลโก้ที่อัพโหลด → ไฟล์ `res/drawable/logo_<key>.png` (ฝังตอน build, เช่น `logo_hbo.png`) → ชื่อช่อง → ไอคอน (ช่อง genre)

## เสียง DTS-HD / ตำแหน่งซับ

- Settings → PLAYBACK มีปุ่ม **DTS-HD**: `PASSTHROUGH` (ค่าเริ่มต้น ส่งตรงไป AVR) / `CORE ONLY` (ส่งเฉพาะ DTS 5.1 core ใช้เมื่อ AVR ถอด DTS-HD ไม่ได้) / `CONVERT` (ให้เซิร์ฟเวอร์แปลง DTS-HD เป็น Dolby Digital) — เปลี่ยนแล้วกลับไปหน้า TV จึงมีผล
- Sub position ปรับได้ −20% ถึง 50% (ค่าติดลบ = เลื่อนซับลงต่ำกว่าขอบล่างของภาพ ใช้กับซับ SRT/text)

- DTS-HD MA ในไฟล์ MKV มักถูกติดป้าย `A_DTS` ทำให้ ExoPlayer ส่งแค่ DTS core (AVR ขึ้น "DTS" เฉยๆ) ตอนนี้แอปดูข้อมูลสตรีมจากเซิร์ฟเวอร์ ถ้าแทร็กเป็น DTS-HD จริงจะส่งเป็น DTS-HD ให้เต็ม (โหมด PASSTHROUGH)
- หน้า Guide: กด ◀ ที่รายการแรกของแถวเพื่อไปกล่องชื่อช่อง และกด ▶ จากกล่องชื่อช่องเพื่อกลับไปรายการที่ฉายอยู่; ซีรีส์แสดงเลขตอน (S01E02) ในกล่องรายการ

## หน้าตาแอป

- ชื่อแอป **Bendit TV** (package เดิม `app.novatv` จึงติดตั้งทับของเดิมได้ ตั้งค่าและเซิร์ฟเวอร์ไม่หาย)
- เปิดแอปมีโลโก้ขึ้น ~2.5 วินาที (กดปุ่มใดก็ข้าม) รูปคือ `app/src/main/res/drawable-nodpi/logo.webp` (โลโก้สี่เหลี่ยมวางกลางพื้นหลังสีเข้ม)
- กด BACK ตอนอยู่หน้าภาพปกติ จะขึ้นถาม "Exit Bendit TV?" เลือก YES, EXIT / NO, STAY
- ไอคอนบน Shield (banner) คือ `res/drawable-xhdpi/banner.png` (640×360, ใช้รูปกว้างโลโก้ + ทีวีในห้อง) ไอคอนแอปบนมือถือคือ `res/drawable-nodpi/ic_launcher_fg.png` + `res/mipmap-xxxhdpi/ic_launcher.png`

## Direct play ถูกปฏิเสธ (HTTP 403)

ถ้าเซิร์ฟเวอร์ตอบ 401/403 ตอนดึงไฟล์ตรง (มักเกิดเมื่อบัญชีที่ใช้ไม่ได้รับสิทธิ์ "Allow media downloading" ใน Jellyfin/Emby หรือไม่ได้รับสิทธิ์ดาวน์โหลดใน Plex) แอปจะข้ามการลองซ้ำ จำว่าเซิร์ฟเวอร์นั้นห้ามไฟล์ตรง แล้วสตรีมผ่านเซิร์ฟเวอร์ (โหมด SMART) ให้ทุกเรื่องของเซิร์ฟเวอร์นั้นทันที — การเปลี่ยนโหมดเล่นใน Settings จะล้างความจำนี้ ถ้าอยากใช้ direct play ได้จริง ให้เปิดสิทธิ์ดาวน์โหลดให้บัญชีนั้นบนเซิร์ฟเวอร์

## เสียง / ซับตอนสตรีมผ่านเซิร์ฟเวอร์ (Plex)

Plex transcoder ใช้แทร็กเสียง/ซับที่ "บันทึกไว้" ของไฟล์นั้น ไม่ใช่พารามิเตอร์ใน URL เสมอไป ตอนสตรีมผ่านเซิร์ฟเวอร์แอปจึงสั่ง `PUT /library/parts/<id>?audioStreamID=…&subtitleStreamID=…` ก่อนเริ่ม (เหมือนที่ Plex Web ทำ) ผลข้างเคียง: แทร็กที่เลือกจะถูกบันทึกเป็นค่าของไฟล์นั้นใน Plex ด้วย

## ถ้าเล่นไฟล์ไม่ได้

แอปไม่ข้ามรายการและไม่เลื่อนนาฬิกาตารางอีกแล้ว แต่จะลองตามลำดับ: ลองใหม่ 1 ครั้ง → สลับเป็น transcode ผ่านเซิร์ฟเวอร์ (หรือกลับเป็น direct play ถ้าตั้ง transcode ไว้) → ถ้ายังไม่ได้ จะขึ้นหน้าจอ "CAN'T PLAY THIS TITLE" พร้อมรหัสสาเหตุ แล้วรอรายการถัดไปตามตาราง

## ข้อจำกัดของเวอร์ชันนี้

- ยังไม่มีหน้าสร้างช่องกำหนดเอง
- พารามิเตอร์ transcode เขียนจากเอกสาร API ของแต่ละเซิร์ฟเวอร์ ยังไม่เคยทดสอบกับเซิร์ฟเวอร์จริง ถ้าโหมด SMART/ALWAYS ใช้ไม่ได้ให้บอกว่าเซิร์ฟเวอร์ตัวไหน จะได้ปรับ
- ตารางเวลาวนตามเวลาจริงของเครื่อง (ทุกเครื่องที่ใช้คลังเดียวกันจะเห็นตารางเหมือนกัน)
- ฟีเจอร์ใหม่ (preview ใน Guide, ปรับตำแหน่ง/delay ซับ, ตัวอ่านซับ) ยังไม่เคยทดสอบบนเครื่องจริง
- โค้ดชุดนี้เขียนโดยไม่ได้คอมไพล์จริง ถ้า build ครั้งแรกขึ้น error ให้ส่งล็อกจาก GitHub Actions มาแก้ต่อได้
